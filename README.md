# Pharmacy Management System (JavaFX)

A desktop application built using **Java and JavaFX** to manage pharmacy products efficiently.  
This project demonstrates strong use of **Object-Oriented Programming (OOP)** concepts such as inheritance, abstraction, and interfaces, while providing an interactive graphical user interface.

---

## ✨ Features
- Manage different types of pharmacy products:
  - **Medicine** (with expiry dates, dosages, etc.)
  - **First Aid items**
  - **Self Care products**
  - **Medical Devices**
- Implements an **Expirable interface** for products with expiration dates.
- Input validation and error handling for better reliability.
- Clean and modular design following OOP principles.
- Simple and intuitive **JavaFX UI**.

---

## 🛠️ Technologies Used
- **Java (OOP, Exception Handling)**
- **JavaFX** (for GUI)
